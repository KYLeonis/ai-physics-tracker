## Video library repair and source materials

Fixed original Mac OpenCV wheels are recorded in
`packaging/opencv_macos_inputs.json`: host headless 4.14.0.94 and runtime regular /
headless 4.11.0.86. All original artifacts are SHA/size verified. Both versions
were measured to contain GPL-enabled Homebrew FFmpeg; a version rollback would
not repair this issue.

Official FFmpeg 7.1.1 source SHA256:
`733984395e0dbbe5c046abda2dc49a5544e7e0e1e2366bba849222ae9e3a03b1`.
Each build extracts and compiles fresh source; only the verified tarball is cached.
Six same-major-ABI FFmpeg dylibs replace the original video libraries. GPL,
nonfree, version3 and autodetected external dependencies are disabled. Unused
Homebrew libraries are pruned, loader paths relocated, wheel RECORD rewritten
and native files signed. Actual library license/configuration and dependency
checks reject GPL/nonfree or unresolved external closure.

The source archive includes the exact tarball, configure log, fixed wheel inputs,
FFmpeg/ffprobe build scripts and wheel repair script. Independent review checked
these against committed inputs and verified native/wheel hashes. Historical
OpenCV compile-time build information is not evidence for the replaced libraries.

This does **not** assert the entire AI runtime is GPL-free: its separate
imageio-ffmpeg executable remains a distinct GPL component. Full release source
materials and other P6 release gates remain tracked separately. See ADR-0023,
`packaging/SOURCE-MATERIALS.md` and `packaging/NOTICE-third-party.md`.
