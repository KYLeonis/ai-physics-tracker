## Failures and repairs

1. First native preparation build passed frozen smoke then failed unsigned manifest
   argv on macOS system bash3.2 (`MANIFEST_ARGS[@]: unbound variable` under set-u).
   9ebc37c uses a nonempty argv array. Not counted as a successful candidate.
2. Second build passed smoke/DMG, but root changed source-material docs while it
   was running; source snapshot guard rejected `Source changed since build`.
   This was not planned fault injection. Subsequent builds require no concurrent
   source mutations; no inconsistent artifact was accepted.
3. 9ebc37c packaging37137073614: Windows success; Mac scanner mistook Qt TLS
   binary's PEM label for private credentials. 4037ec7 scans UTF8 text, no size
   cap, rejects ordinary video/weight/key formats; old actual App2456-entry
   inventory succeeds. Tests include a native binary label and >2MiB text key.
4. `codesign --verify --deep --strict --verbose=4` after native smoke listed
   new worker-src `__pycache__/*.pyc` as added resources. Shared worker argv
   now uses `-B`; a real hello worker on an isolated source copy must leave its
   entire source tree byte-for-byte unchanged. No changes to user App/projects.
5. Independent Review found incomplete ignored-input/worker provenance, narrow
   privacy scanner and misleading LGPL opening statement. Fixes reject ignored
   source/resource/license inputs, expected worker hashes come from tracked
   commit snapshot, expand privacy boundary and distinguish cv2 GPL. Final
   review outcome pending; record linked below once complete.
6. New input guard caught one existing original1148-byte NVIDIA cudnn_frontend
   notice ignored by generic `cudnn*/`. Exact license-text exception added to
   .gitignore and original text committed; CUDA binaries remain excluded. This
   makes local/CI material provenance consistent, without altering any license.
