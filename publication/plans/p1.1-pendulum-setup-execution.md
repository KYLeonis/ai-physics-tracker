## 实现要点(按 Slice)

### S1 — v2 domain/serializer skeleton

- `domain/paths.py`:从 `video.py` 提取 managed 相对路径校验(相对根、POSIX、拒绝 `..`/绝对/Windows 保留名),Video 与新 payload 路径共用。
- `domain/types.py`:新增 `canonical_json_digest`(sort_keys、separators、allow_nan=False 的 canonical JSON → sha256 hex)。
- `domain/pendulum.py`(新):`ROLE_ORDER`、`PendulumRoles`(四字段 tip/body_top/body_bottom/pivot,构造期强制 distinct)、`TrueVertical`(端点有限且不重合;`direction_confirmed` 时 `confirmed_digest` 必须与端点 canonical digest 一致——加载即防篡改)、`PendulumGeometry`(fixed_pivot_px/true_vertical/tip_radius_reference_px,全部可 null)、`PhysicalParameters`(length_m/g_m_s2 正有限 + 非空 provenance)、`RoleBindingEditRecord`、`ExperimentActivationRecord`、`PendulumExperiment`(mode/contract_version/measurement_revision/release_frame_index/active_infer_run_id/activation_history/extra_fields)。
- `domain/scientific_result.py`(新):`ResultColumn`、`ResultPayload`(format json|csv、相对路径经 paths 校验、size、sha256 hex、columns)、`ScientificResult`(experiment_id、kind、input_digest、execution_status/freshness 枚举、core_version)。P1 只做 envelope 验证与无损保存,无 producer。
- `domain/tracking_run.py`:`track_id` 字段改为 `member_track_ids: tuple[UUID, ...]`,新增 `experiment_id`/`role_bindings: PendulumRoles | None`(二者同时出现或同时缺省);保留 `track_id` 只读 property(单成员,多成员 raise——fail closed 兼容访问器);`create_tracking_run` 接受单 UUID 或序列。
- `domain/project.py`:`Project` 新增 `required_capabilities: tuple[str, ...]`、`migration: MigrationRecord | None`、`experiments`、`scientific_results`;`validate_project` 扩展:v1 模式(capabilities 空)不得携带任何 publication 事实;v2 模式 capabilities 恰为 `("pendulum-four-role-v1","scientific-results-v1")`、experiment 四 role 同 video 且跨 experiment 不复用 Track、每 video 最多一个 experiment、release 帧界、active run 结构校验(completed infer、四成员=当前 roles)、run 成员存在且同 video、pendulum run 恰四成员=roles 规范序、generic run 单成员;`delete_track` 拒绝 experiment-bound Track 并按成员级联 run。
- `infrastructure/project_serializer.py`:`project_to_payload/from_payload` 按 project/payload 的 format 分派;v2 顶层 `schema_version=2` + `required_capabilities` + keyed map(`experiments`/`scientific_results`,key 必须等于对象 id)+ v2 run 形态(`member_track_ids` 必填);v1 输出保持现状(含 exchange 用 `tracking_run_to_payload` 写单成员 `track_id`,多成员显式报错);v2 读侧拒绝 unknown capability、key/id 不一致、悬空/跨 video 引用。
- `infrastructure/project_repository.py`:支持读到 v2(`CURRENT_SCHEMA_VERSION=2`),version>2 拒绝;删除自动迁移循环——v1 是被永久支持的终态格式,升级只走显式 Save As(ADR-0017)。
- 测试:`tests/test_pendulum_experiment.py`(domain 不变量)、`tests/test_project_serializer_v2.py`(双格式 round-trip/拒绝矩阵/envelope 无损)、更新 `tests/publication/test_legacy_reader_boundary.py`(合法 v2 现在应加载;缺/未知 capability 仍拒绝)、机械更新全部 `TrackingRun(track_id=…)` 构造。

### S2 — Save As migration service

- `ProjectRepository.save_as_publication(source_root, destination_root, project)`:source manifest 必须为 v1;candidate 携带 publication capabilities 且无既有 migration 记录;repository 计算 source manifest sha256、写入 `MigrationRecord`、经既有 `_publish_project`(staging sibling + copytree 保留 UUID/unknown siblings + 原子 rename)发布;任何失败保留 staging 恢复路径、源目录零改动。
- 故障注入测试:copy/write/replace 失败、Unicode/Windows-safe 目录名、源 manifest hash/backup 不变。

### S3 — experiment/session invariants and guards

- `ProjectSession` 新增:experiment create/bind/rebind/delete(一次提交完整四 role;rebind 同事务清旧四成员 AI projection、保留 manual、active 指针置空、history+revision)、snapshot 扩展(undo/redo 覆盖 experiments/scientific_results)。
- 旧单轨 AI mutator guard:`import_engine_points`/`activate_infer_run`/`replace_active_infer_run`/`clear_active_ai_observations`/`prepare_tracking_request`(bound Track 一律 ProjectSessionError,Project/Store/history 不变)。
- `application/pendulum_setup.py`(新,Qt-free):setup completeness 投影与 experiment 依赖 digest(calibration/geometry/physical/release/roles 进入 digest;calibration 编辑/切换/删除 → 结果 stale 且不偷换 Calibration)。
- → data/compatibility Independent Review(subagent 只读,Flash),关闭 blocking 后才接 GUI。

### S4 — geometry/release application actions

- Session 动作:set_fixed_pivot、set_true_vertical(改端点即撤销确认)、confirm_true_vertical、set_physical、set_release_frame;每次 revision+1、相关结果 stale、单次 undo 快照。

### S5 — setup GUI/workflow projection(P1.1 独有 GUI)

- Pendulum 创建/Save As 向导、四 role picker/create、视频 pivot/vertical 点选、L/g/release 控件、setup checklist/task card;复用 calibration UI。

### S6 — integrated save/reopen and review

- offscreen GUI + 全量回归 + 迁移失败探针 → Human Review(用户)→ Independent re-review → 集成。
