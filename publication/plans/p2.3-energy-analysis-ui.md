## Scope / Acceptance Criteria

- [ ] reference potential = q(1−cos θ)，kinetic = ω²/2，reference energy 为两者之和，q=g/L 明确单位 s⁻²；与 fitted energy 分开。正有限物理值、有限输出、None+reason，无无关质量假设。
- [ ] 非线性无阻尼解析能量恒等式验证；缺口/短段能量不补零；所有列保留原始 frame、绝对/释放相对时间、共同 QC、导数 edge、四 role 来源。
- [ ] Qt-free 数值 core；应用消费 adopted snapshot 后一次 current assert；结果 input digest 覆盖实际测量、resolved interval、profile、core/dependency versions、物理 L/g。
- [ ] 后台 detached 工作，不持有 Qt；取消、关闭/换项目、输入变化及迟到结果不能替换有效结果；错误有可读原因。
- [ ] scientific_results typed scalar JSON payload 新 ID、相对路径/size/SHA，先 immutable 文件后项目事务。失败不损旧结果；保存重开/Save As payload 可携带；旧 v1 通用图表仍走既有路径。
- [ ] 分析页默认 student SG9/3；θ/ω 时间图、相图和 reference energy 图明确单位、来源、缺口、edge/period/tail不足状态。点击实际数据点跳对应源帧；返回获取页修正后旧结果显示 stale，重算恢复。
- [ ] 显式选定当前 tip 与 fixed pivot 的几何半径参考（只作 QC，不充当物理 COM 长度）；缺 setup 时指出缺项。可指定 post-release 末帧，tail 为所选时域最后 1/3。
- [ ] 定向/全量/evidence 验证、Independent Review、真人 Human Review 后才集成 push / P2 收尾。
