已有main .venv，最短启动：

```bash
cd /Users/leonis/Documents/ai-physics-tracker-ejp
PYTHONPATH=src /Users/leonis/Documents/ai-physics-tracker/.venv/bin/python -m ai_physics_tracker
```

1. 打开test1或自己的Pendulum项目 → Analysis charts：应看到Kinematics/ODE fitting两个页；原来的SG图仍在Kinematics。
2. 进入ODE fitting，先选M0/High precision。若释放前5帧有效且实际静止，勾选held-rest确认；否则选Explicit，填写θ₀/ω₀。先计算当前Kinematics且release帧有效时，可点击Fill θ₀；静止释放的ω₀为0。
3. Run fit → 窗口可操作，有进度；完成看到角度overlay、raw residual、参数/单位和full RMSE。点击观测/残差点 → 右侧视频与Source frame一致。
4. 选Compare M0+M1或修改Advanced → 旧图保留且设置待应用；再次Run后点击Cancel → 旧结果保留。再完成一次比较 → M0/M1参数、曲线、comparison或不可比较原因清楚。
5. 完成后保存、关闭并重开 → 结果/实际配置可恢复。修改一个tip再回分析 → 旧fit显示STALE，重算才能恢复当前状态。
