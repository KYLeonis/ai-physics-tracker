## Slices(计划 §7 顺序不变)

### S1 — product external runner(High-risk:进程/并发/取消)

- `infrastructure/external_worker.py`(host):依赖注入 runtime Python 路径(dev=当前 venv,frozen=未来 managed runtime);每 job 独占目录 `data/engines/<job_id>/`:`request.json`/`result.json`/`cancel.request`/`worker.log`;`request_digest`=canonical request(含 worker 源字节 SHA、op、device)SHA256;subprocess shell=False、清理 PYTHONHOME/PYTHONPATH。
- worker 入口 `python -m ai_physics_tracker.worker`(新顶层模块):仅受信操作(枚举白名单);versioned JSON schema(protocol_version=1);exit 约定 success/cancelled→0、failed→1;result 临时文件 + `os.replace`;worker 不持有 session、绝不写 project.json。
- host 验证:request/result 身份一致、exit/status 匹配、输出路径 containment + size/SHA、runtime/device 字段;迟到结果(取消/超时后)拒绝登记;重复 job 目录拒绝。取消:cooperative marker + 有限 grace;强制回收 POSIX killpg,Windows taskkill /T /F(真机 G4 门禁在 P6 前补)。
- GUI 语义:复用现有 task handle/poll(FrameSelectionActions 模式),不自建线程模型。
- 测试:协议 schema 负例(wrong job/digest/status/exit/device、路径逃逸、hash 不符、duplicate 目录、迟到 result)、取消树、畸形/超大日志 payload;hello/selftest 操作用假 runtime python 脚本驱动。

### S2 — joint training request/result(High-risk:数据契约)

- `application/experiment_training_job.py`(prepare,Qt-free):从 experiment 构建不可变 request——四 member/role snapshot、complete label snapshots、共同 split、input digest、config/seed/runtime identity;**唯一路径** join→export→split_indices(复用 P1.2 函数,不重写);stale(标注/role/video/runtime 变更)拒绝。3/4 partial 帧结构性不出现(join 只出 complete)。
- worker 侧 `train_experiment` 操作:dataset 创建→训练→评价(经 DLC adapter);progress 经日志行,不进协议 JSON。
- result verifier:runtime 身份、恰好四规范 bodyparts、checkpoint/config 落在 run-owned 路径、digest 匹配 → 登记 completed candidate(multi-member run,member=四 role tracks)。
- 测试:request 不变量(role order/split/digest/stale 六负例)、不能四次单点训练冒充联合(run member 断言)、verifier 负例(checkpoint 外逃/bodypart 错序/缺 config)。
- S1 review 交接项(i3–i6):①超时策略在本层——超时必须调 `handle.cancel()`(置 `_cancel_requested` 才能拒绝迟到 success),裸 poll+read 不设防;②host 记录 elapsed_s(started_at/finished_at 已在 result);③跨会话采信 job 目录结果前需持久化 lifecycle 状态(仅靠非空目录拒绝不够);④Windows taskkill /T 假设"存活父子链"——列入 G4 真机 checklist。

### S3 — trained model reference + Independent Review gate

- `domain`:`TeacherModelReference`(origin=trained/imported、source_train_run_id、immutable manifest:逐文件 SHA+相对路径、created_at);serializer round-trip(unknown-optional 兼容)。
- session:completed train run 验证 checkpoint 属于本 run/config → 建 reference;save/reopen 一致;文件 missing/modified → unavailable(不静默找替代)。
- **Independent Review(High-risk:AI lifecycle/协议/并发)**:S1–S3 整体审查 worker 协议、取消/迟到、request 唯一路径、manifest 完备性;blocking 关闭后才进 S4。

### S4 — teacher import core(High-risk:文件事务/安全)

- `application/teacher_import.py`(Qt-free):目录→safe YAML 解析(非 mapping raise,复用 EX2 模式)→显式 bodypart mapping(missing/duplicate/extra/multi-animal/cropped/不支持 engine 全 fail closed)→managed copy 到 `models/<model_id>/staging`(逐文件 SHA、路径重写、拒绝绝对路径逃逸)→atomic publish;origin=imported、source_train_run_id=null。
- fault injection:半拷贝中断、同名覆盖、路径逃逸、Unicode/长路径;原目录移动后项目内模型仍可用。
- 测试用最小合法 config fixture(不依赖真实大 checkpoint,hash 以任意字节即可)。

### S5 — runtime compatibility self-test

- 同一 external worker `selftest_model` 操作:真实 load 选定 checkpoint + 单帧/极短合法输入 infer;记录实际 runtime/python/device/version + input/model digest → compatible(此前 static parse 仅 unverified);证据变化 → 重新验证。trained 与 imported 共用同一 validator。
- 测试:unverified→compatible 状态机、证据失效、MPS 不可用显式失败(CPU fallback 属产品合同,本轮不自动 fallback)。

### S6 — training/import GUI and closure

- 测量卡 secondary "Run joint training"(experiment 级;沿用 P1.2 测量卡);File 菜单 "Import DLC Model…";mapping 向导(显式映射 UI)、compatibility/结果/日志展示;cancel/retry 用新 run/model ID。
- 真实 DLC 双路径 smoke(macOS arm64):①test1 数据 tiny 联合训练→reference→selftest compatible;②构造最小教师目录→import→selftest。不设精度目标。
- Human Review(交互:导入向导/训练进度/取消)+ independent re-review + 集成合并。

## Acceptance Criteria(自计划 §7,逐项可验证)

- [ ] joint train request 含四 member/role snapshot、4/4 label snapshots、共同 split、input digest、config/seed/runtime identity;任何 3/4 frame 不出现。
- [ ] external worker 不持有 session、不写 manifest;request/result identity、status/exit、path containment、size/SHA、runtime/device 均验证;取消/超时/迟到结果不登记 completed model。
- [ ] 一次 DLC project/dataset/train 恰含四个规范 bodyparts,单 run 产生可验证 checkpoint/config;不能四次单点训练冒充联合训练。
- [ ] trained model reference 指向本项目 completed train run 且 manifest 一致;imported 的 source_train_run_id=null,不制造 training history。
- [ ] teacher bundle 全部复制到 project-managed path;原目录移动后仍可用;缺文件/hash 变化/配置逃逸 → unavailable/incompatible,不静默寻找替代。
- [ ] mapping missing/duplicate/extra、multi-animal、identity tracking、cropping、不支持 engine 均 fail closed 且不发布 model reference。
- [ ] static parse 只得到 unverified;当前 runtime 真实 load/infer 成功才 compatible;证据记录实际 runtime/device/version 与 input/model digest。
- [ ] save/reopen 后 run/model/mapping/compatibility state 一致;generic unbound single-track train workflow 保持兼容(回归)。
- [ ] (EX4)训练 request 冻结全量 label digest,唯一路径 build→rows→export→split_indices。
