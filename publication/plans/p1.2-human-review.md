## 1. 准备

## 2. 验收步骤(操作 → 预期 → PASS/FAIL/N-A)

### HR-A 引导标注主流程(S3 核心)

| # | 操作 | 预期 |
| --- | --- | --- |
| A1 | Pendulum experiment 面板点 "Mark landmark frames…" | 进入引导:无需选 track,引导条提示 "click the tip";视频上四条 role 轨迹的点全部可见 |
| A2 | 按提示依次点击四个 landmark | 每次点击落到当前提示的 role(点出现在画面上);引导条推进:tip → body_top → body_bottom → pivot;计数 1/4 → 4/4 |
| A3 | 4/4 后观察引导条 | 显示 "complete (4/4)";按钮变为 "Next frame (N)"(帧集有下一帧时)或 "Finish guided marking" |
| A4 | 点 Next frame | 跳到帧集下一帧,引导重置为 0/4,继续 A2 |
| A5 | 中途按 Esc | 退出引导;**已标的点保留**(partial 状态);重新进入引导后从当前帧继续 |

### HR-B partial 与跳过

| # | 操作 | 预期 |
| --- | --- | --- |
| B1 | 某帧只标 2 个 role 后点 "Skip body_bottom"(跳过按钮) | 引导跳到 pivot;标注后该帧 3/4 partial |
| B2 | partial 帧上继续走 Next/Finish | 允许;帧保持 partial(引导条曾提示 never used for training) |
| B3 | Undo(Ctrl+Z)/Redo 若干步 | 点的增删完整往返;引导计数随之变化 |

### HR-C 帧集持久化

| # | 操作 | 预期 |
| --- | --- | --- |
| C1 | Save → 关闭 → 重开项目 | 共享帧集仍在;重新进入引导可用 |
| C2 | (如做过)再次 Suggest Frames | 新帧集替换旧集,undoable |

### HR-D 错误可操作性

| # | 操作 | 预期 |
| --- | --- | --- |
| D1 | 尝试对 bound track 走单轨训练/推理 | 按钮禁用并显示原因(P1.1 已验收,回归确认) |

## 3. 封闭式问题

- **Q1** 四 role 的引导顺序与提示是否清楚"现在要点哪个"?A 清楚 B 模糊(注明) C 混乱
- **Q2** partial 帧的处理(可保存、不进训练)是否表达清楚?A 清楚 B 模糊
- **Q3** 引导条按钮(Skip/Next/Finish)行为是否符合预期?A 符合 B 有问题(注明)
- **Q4** 有无让你犹豫超 10 秒的地方?A 没有 B 有(简述)

## 4. 通过标准

1. HR-A/B/C/D 全部 PASS(或 N-A 且理由成立);
2. Q1–Q4 无 C 级/严重问题回答;
3. 数据安全一票否决:引导标注丢点、重开丢帧集、undo 破坏状态任一出现即不通过;
4. blocking FAIL → 修复后只重测受影响项;UX 类由你裁定修或延后;
5. 通过后:P1.2 收尾(合并、文档)并停止,等待 P1.3 授权。
