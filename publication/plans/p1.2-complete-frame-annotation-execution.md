## Slices(计划 §6 顺序不变)

### S1 — experiment frame-set model and projection

- `domain/pendulum.py` 增 `ExperimentFrameSet`(frozen):`frames: tuple[int, ...]`(ordered unique、每个 < video.frame_count)、`algorithm: str`、`seed: int | None`、`working_zone: tuple[int, int]`、`video_sha256: str | None`、`created_at`、`extra_fields`;构造期校验排序/去重/越界。
- `PendulumExperiment` 增 `frame_set: ExperimentFrameSet | None = None`(setup 分步语义:None=未选帧);**不改 activation_history 语义**(frame set 变更走 measurement_revision+1,由 session 动作承担)。
- serializer:`experiment_to/from_payload` 增 `frame_set` 键(unknown-optional 向后兼容:P1.1 落盘的 v2 项目无此键也能读)。
- `application/experiment_frames.py`(新,Qt-free):`replace_frame_set(project, experiment, frame_set)` 纯函数(revision+1、scientific results stale);selection request 的 owner identity 扩展(experiment_id 而非 track_id,复用 uniform/K-means worker 的可行性以勘探结果为准)。
- 测试:domain table(frames 排序/去重/越界/空)、serializer round-trip(旧 v2 payload 无 frame_set 键 → 读为 None → 再存带键)、session 动作 revision/stale/undo。

### S2 — pure 4/4 join/completeness

- `application/annotation_join.py`(新,Qt-free 纯函数):
  - `join_complete_frames(project, experiment) -> JoinResult`:`complete: tuple[CompleteFrameLabel, ...]`(按帧排序;每帧 = frame_index + 四 role 的 active manual TrackPoint 引用(point_id/revision/坐标))、`partial: dict[int, int]`(帧→已标 role 数 1..3)、`diagnostics`(duplicate/AI-only/superseded 计数)。
  - 判定严格按契约 §3:同一 frame_index 上四个 role 各有一个 active manual、finite、非 superseded;AI 点不计;跨 video 结构上不可能(roles 同 video 不变量)。
  - `canonical_label_digest(join_result)`(canonical JSON,进训练 request 与 fixed-check 快照)。
- 负例与属性测试先行:0/4→4/4 矩阵、AI 补点拒绝、superseded 拒绝、role rename 不影响(只认 UUID)、任一点 revision/坐标变化 → digest 变、显示名/颜色变化 → digest 不变。

### S3 — guided annotation transaction/UI

- `gui/experiment_annotation.py`(新):同帧四 role 顺序引导(提示当前 role、overlay 高亮)、Complete/Next gate(4/4 才可下一帧)、partial 退出保留。
- `main_window`:experiment 存在时标注模式路由到 role 顺序提示;复用现有 annotationClicked/track 选择结构,**不建第二套落点路径**(仍是 session.mark_point 到 role 对应 track)。
- Undo/Redo、改点、删点、frame/video 切换全部经既有 session 动作。
- 增量 Human Review(计划指定)。

### S4 — shared fixed-check

- fixed-check 为 experiment 级 frame membership(复用 ValidationSeries 概念但不写四份 per-track series):`domain` 增 `ExperimentFixedCheck`(frames + 四 label snapshot + digest);session 动作 freeze/renew/deactivate;任一 role label 改动 → invalid。
- exporter 的 split 排除以 membership 为准。

### S5 — four-bodypart exporter

- `dlc_adapter` exporter 扩展:输入 `join_complete_frames` 的有序结果;一帧一次 decode、一行 8 坐标(tip/body_top/body_bottom/pivot × x/y,规范顺序);duplicate/missing/foreign video 整体拒绝;共同 split 索引基于导出行序,fixed-check 帧共同排除。
- golden structure 测试:PNG 数=complete 帧数、MultiIndex 表头、HDF5/CSV 一致。
- 本 slice 后 identity/export 专项 review(subagent)。

### S6 — DLC-format smoke and closure

- 真实 DLC 3.x:`create_training_dataset` 读取四 bodypart dataset(合成短视频,≥1 train + 1 fixed-check 帧);记录版本/平台/命令;不训练、不声称精度。
- 全量回归 + Independent Review 复审 + Human Review(S3 增量 + S6 终验)→ 合并。
