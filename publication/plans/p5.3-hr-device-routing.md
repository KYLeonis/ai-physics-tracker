# P5.3 HR follow-up — selected device and automatic GPU routing

- 2026-10-02；branch `codex/ejp-p5-3-student-pilot`；base `ba09af5`；root实施。
- Risk：High-risk（模型自检设备/worker身份与GUI连续任务）；required readonly Independent Review + Human Review。

## Goal / Agent Context Pack

Advanced settings选的device/训练参数真正进入联合工作流。auto在worker所用runtime解析cuda→mps→cpu，推理先在所选设备做真实单帧自检；成功后使用相同已验证backend，保留实际设备证据。

- Authoritative：用户当前auto要求；runtime-boundary Protocol v1；P1.3兼容证据、P1.4 request/result验证；P5.3工作流与既有进度。
- Reuse：TaskPanel training/inferenceParameters；DLCAdapter.detect_device；ModelActions selftest续跑；request.expected_device、runtime self-test证据及原验证器。
- Findings：协议DEVICE_BACKENDS此前不允许auto，已有worker auto分支不可达；本轮允许auto请求（向后兼容，terminal仍报告明确backend），强化selftest_model设备匹配验证。GUI训练未传params且auto改cpu；推理chooser、launch、自检三处固定cpu。auto不能沿用CPU self-test当GPU证明。
- Invariants：显式设备不静默换后端；auto只能选已支持可用backend；换session/experiment、取消/自检失败不续推理；候选仍需原hash/digest/runtime验证及显式采用。当前用户在途任务/工程数据不修改。
- Non-goals：新依赖/DirectML/XPU、P6打包、静默开启compile/autocast、在当前内存紧张且CPU推理在途时启动重模型benchmark、宣称Windows/MPS实测通过。

## Scope / Acceptance Criteria

- [ ] Joint training读取Advanced参数且auto交给worker解析。
- [ ] Joint inference默认继承Advanced device并可显式选择；auto每次解析/单帧自检后才启动，显式设备已有同backend证据可复用；运行阶段显示requested→actual。
- [ ] GPU自检失败/取消不启动推理，不把CPU证据当GPU通过；返回CPU仍可重试；结果device与自检、worker请求一致。
- [ ] 训练/推理/自检参数回归、CUDA/MPS/CPU探测矩阵、取消/session边界验证；Independent Review与最终双平台CI通过。
- [ ] 新device选择与Activity说明Human Review通过（用户操作）；真实MPS/CUDA成功与速度只按实际测试记录。
- [ ] compile/autocast按已安装DLC源码与官方资料解释：可能有收益，compile有冷启动/兼容成本，autocast改变精度；默认关闭，优先验证GPU，后续短片对照后决定。

## Slices / Review Gate

1. 既有设置→chooser/train参数→device自检续跑→已验证backend推理。
2. mock runtime/真实Qt与session回归；实际设备记录及原结果门禁。
3. 固定SHA只读Independent Review、双平台CI、文档同步/push；给从零启动与封闭式HR并停止。

## Result

实施中。Windows没有CUDA时本版本只能选择CPU；不把未安装/未接入的GPU后端当成可用选项。compile/autocast不自动开启，保持现有模型文件不变。
