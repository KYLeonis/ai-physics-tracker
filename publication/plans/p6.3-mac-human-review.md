## S3 · 两条实际任务（安装版内）

素材：`build/p6.3-mac-rc/synthetic-pendulum-36f.mp4`（36 帧合成视频，四个不同颜色
的点；只验证功能链，不评估识别精度）。也可换成你自己拍摄的短片段（作为输入只读）。

**任务 A · 自训循环**：

1. `File → Open video (new session)…` 打开该视频，`Create Pendulum experiment…`
   新工程目录。Setup 按界面完成（标定数值只需合法，不要求物理意义）；时序为 CFR，
   不应出现近似授权询问。
2. `Acquire → 1 · Recommend 20 frames` → `2 · Label recommended frames`：每帧按
   `tip → body_top → body_bottom → pivot` 顺序标四个色点，四点完成自动跳下一帧。
3. `3 · Train / retrain`：Advanced 设 epochs=1、**device=cpu**、batch 小值；确认
   fixed-check 后训练。完成 → `4 · Verify & run inference`（全片 36 帧推理）→
   出现待审核候选（**不自动采用**），Review 后 `Use candidate for analysis`。
4. `5 · Mine difficult frames`：只勾少量帧，补齐四点，Done 后重训 → 再推理。
   记录每轮训练配置、实际 device、帧数与终态。
5. **MPS 单列**：再把 device 设 `mps`（或 auto）做一次短训练或推理，记录实际
   结果；失败就如实记录错误并切回 cpu，不算阻塞。

**任务 B · 教师模型导入**：

1. 新建另一个实验工程（同视频、同 Setup）。
2. `Import teacher model…`：选任务 A 训练出的模型目录——工程目录下
   `data/engines/<最新 run id>`；检查四角色映射。
3. `Verify & run inference`：自检 → 推理 → 审核采用。记录自检与推理的
   requested/actual device。
