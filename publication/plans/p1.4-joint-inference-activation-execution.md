## Scope / boundaries

交付 §8 的 S1–S6 和全部 AC。raw 四 role artifact 是 candidate truth，完成推理不自动写 TrackStore；tracked pivot 只用于 QC 和 P2 handoff，fixed pivot 保持实验 setup 真值。P1 不计算 θ、科学 mask 或拟合，不引入新的 confidence 科学阈值。

## Slices

1. **S1 联合推理**：严格四 bodypart/scorer/coord/frame parser；compatible model + video/timing + role binding 的不可变请求；worker 单次 DLC analyze；host 对 model/video/artifact SHA、request digest、summary、stale 复核；completed run 仅为 candidate。自训与 imported 共用路径。真实 Mac CPU 短视频验证。
2. **S2 审核/QC core**：按 frame 聚合四 role 原始预测与缺测/置信/geometry/pivot 诊断；run-scoped Accept/Skip/Correct；Correct 仅对选定 role 写 manual 并增加 measurement revision。阈值 provenance 明示。
3. **S3 四轨事务**：候选四轨 TrackStore 与 experiment pointer/history/revision/stale 一次 commit；Activate/Replace/Clear/Undo/Redo/save-reopen，manual 保留；错误注入和 bound-track 旧入口全矩阵。完成即做 data-loss/transaction Independent Review，blocking finding 清零后接 UI。
4. **S4 workflow/UI**：experiment 级 infer/progress/cancel/log、四点 overlay 与审核队列、candidate/active 清晰状态、四轨操作确认及 history。offscreen 测试后由真人 Human Review 体验。
5. **S5 P2 handoff**：Qt-free、只读 adopted measurement snapshot，冻结 absolute frame/time、四 role source/confidence/missing、fixed/tracked pivot、scale/release/L/g 和 canonical digest；不计算 θ。Scientific semantics Independent Review。
6. **S6 全链验收/收尾**：自训与 imported 两条真实 DLC 推理、取消与迟到、stale/故障、审核修正、激活替换或清除、Undo、重开；全量回归、最终 lifecycle/persistence re-review 和 Human Review；更新状态/证据并合并推送，P1 完成后停止。
