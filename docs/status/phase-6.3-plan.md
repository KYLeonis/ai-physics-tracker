## Scope

### 1. 数据与时间

- 一次一个同视频轨迹 / 标量。选择位置x/y、现有速度 / 加速度分量、角度 / 角速度 / 角加速度；不扩展到任意两列或跨视频。
- 明确选择测量值 / 平滑值，默认测量值；不因当前图表显示平滑曲线而静默拟合它。
- 提供本次分析的起止帧 / 对应时间，默认当前working zone；边界必须落在合法视频区间内，不新增raw编辑。拟合时间从所选左边界计0，缺测后仍按绝对帧映射连续计时。
- 后台保存本次实际样本的source frame、视频时间、拟合相对时间、数值、有效段以及输入 / 标定 / 参考 / 时序身份；预测与残差只对应真实样本，不制造缺测点。

### 2. 公式编辑器

- 文本输入 + 数学排版预览；函数 / 符号按钮、括号与错误位置提示。只读左侧目标量 + 可编辑右侧表达式，避免把显示名字误当计算变量。
- 支持有限实数、括号、`+ - * /`、乘方（`^`及`**`统一含义）、单参数`sin/cos/exp/log/sqrt/abs`与`pi`；`log`为自然对数。乘法必须显式，`At`不猜成`A*t`。
- `t`为保留自变量，其余合法普通标识符列入参数表；函数 / 常数保留名不能同时作参数。显示用希腊字母的映射不得改变标识符身份。
- 明确一元负号和乘方优先级，预览保留必要括号；不能把`-t^2`静默算成`(-t)^2`。
- 输入无效时停止曲线预览 / 拟合并定位错误；有长度 / 深度 / 运算与数值范围限制，除零、溢出、实数域错误明确报告，不静默删去坏预测样本。
- 可编辑线性、二次和阻尼余弦示例；它们使用同一通用解析 / 求解路径，不硬编码物理模型。

### 3. 参数、拟合与结果换算

- 自动列出参数；用户确认初值、可选上下界、固定 / 待拟合。预览初值曲线后启动拟合。示例可建议初值，通用公式不承诺自动识别。
- 普通最小二乘、有效样本等权、用户给定的一组初值与边界；使用现有SciPy，有限评估次数、取消检查、后台执行。
- 参数 / 样本数不够、非有限模型、模型对待拟合参数无敏感性、达到计算上限、明显秩不足等给出具体状态；不能作为正常有效拟合发布。不宣称搜索到全局最优。
- 常量信号允许拟合可辨识的常量模型（如`y=c`）；不能因不振荡就拒绝通用拟合。它不满足周期测量条件，两种工具各自判定。
- 参数全固定时可做模型预览 / 残差计算，并标为“给定参数计算”，不伪装为拟合成功。
- 可选结果计算：用户命名结果并输入仅引用本次参数和允许常数 / 函数的标量公式，如`T = 2*pi/Omega`。只计算一层，不允许换算结果相互引用；除零等错误单独披露，不使原拟合参数消失。
- 结果计算值仅代表用户所声明关系的代入值；不从参数名称自动推断周期、g或模型成立。

### 4. 通用重复间隔 / 周期工具（用户已确认）

- 与用户拟合公式独立，也可不做拟合直接使用；不以是否选择单摆模型作为启用条件。
- 方法为选定信号同方向穿过可见、可调参考线；保留方向、参考线、抑制噪声重复计数的设置及每个交叉事件的源帧夹点 / 插值时间。
- 交叉时刻仅在相邻有效样本之间线性估计，不补写raw。平坦在线、恰落在线、噪声反复穿线、短段、NaN、wrapped角度跳变均有确定规则。
- 每周期恰有一次该方向交叉的信号，交叉间隔才可解释为周期估计。均速直线、单调衰减等没有足够事件时显示“无法估计”，不从用户公式名称猜周期。
- 多峰 / 含谐波 / 非平稳信号可能一周期多次交叉或间隔变化：输出称为“同向交叉重复间隔”，显示事件及逐次间隔 / 数量 / 均值 / 样本标准差；不自动称唯一基本周期或自行推断周期稳定。
- 至少2个有效事件才有一个间隔；只有一个间隔时样本标准差不可估计，不能填0。少于真实基准要求的5个完整周期时不能通过该基准验收。
- 原始角度跨±π不视为实际穿线；需要显式选择适用信号。连续旋转角的单调unwrap信号没有来回穿线时，不声称此方法可测旋转周期。
- 非单摆周期案例、非周期案例和多峰 / 变周期案例均列入验收，避免单摆专用判定泄入通用平台。

### 5. GUI与可追溯结果

- 在既有Analysis内形成“选择数据 → 编辑公式 / 设置参数 → 预览 → 拟合 → 查看结果”；周期工具独立入口，二者可分别使用。参数高级项保持可展开。
- 显示测量 / 拟合叠图、残差图、参数、RMSE、有效样本数、计算 / 收敛 / 可辨识状态；可选结果换算与交叉测量结果分开呈现。
- 点选实际样本可定位只读视频源帧；不改变Acquire标注目标。
- 保存公式、参数与约束、实际样本 / 区间 / 来源、预测 / 残差、结果换算、周期事件与设置；保存重开恢复。当前编辑草稿与已保存结果不同要明确披露。
- 源观测、参考、标定、时序、区间、上游派生结果改变后stale；编辑公式 / 参数则取消本GUI任务，并标明当前草稿未应用。迟到任务不能覆盖新结果。
- 每个轨迹 / 量的拟合和周期分别替换最新结果，Undo/Redo原子化，保留其他分析族 / 未选轨迹 / 未知字段；不顺带建立历史版本库。
