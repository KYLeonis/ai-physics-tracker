## Scope

### 1. Purpose-first analysis, chart-first layout

- 三个英文用途入口：`Explore motion`、`Measure repeat intervals`、`Fit a formula`。分别说明需要什么数据、能得到什么结果、下一步做什么。
- 熟练用户可直达原有量 / 图表 / 公式编辑能力；不强迫每次重走入门流程。
- 大图为主体，旁侧是当前任务的短解释、状态和下一步；窄窗仍以图为主，控件可达，不横向裁切，不重复堆放长说明。
- 轨迹 / 源量名称、坐标方向、单位、测量 / 平滑、区间明确。`y`是当前因变量；RHS的`theta`是参数，不能被默认为另一个观测列。
- 源图表、时序、标定或角度参考缺失时，在当前路径显示原因和对应准备动作。必要的物理信息仍由用户确认，不要求先找另一个标签。
- 分析建议框跟随分析目标和数据就绪状态，不让训练的20帧提示主导已有有效轨迹的分析流程。

### 2. Live initial preview and protected initial estimates

- 公式 / 参数停止编辑片刻后自动预览；合并连续编辑请求，只呈现最新有效草稿。公式排版预览和数值初值曲线明确区分。
- 图旁解释目标量、自变量t、待拟合参数；不含t时直接说明`Fits a constant level; no time variation is modeled`。
- 明确区分`Initial preview`、本次计算结果、`Previous saved result`；旧成功结果可回看，但不得被当成本次完成。
- 初值曲线超出源范围时明确提示并提供查看 / 恢复视图动作，不能静默画在视野外，也不能默认把源信号压成不可读直线。
- 初值估算首批限于直线、二次、带偏置的衰减 / 不衰减振荡示例；单个常数参数可作为直线退化情形，不扩展到多个不可区分常数的万能分解。S0冻结可识别结构 / 参数映射；未知自定义结构解释需要手填，不宣称万能估算。
- 首次选择受支持示例时，可直接准备带`Estimated from data`标记的初值及预览。手工改值 / 恢复已存设置后不自动覆盖；换源或区间仅提示可重估，主动采用才更新。
- 保留用户边界和Fixed设置；不能给出可靠且兼容的建议时明确回退人工输入。正式Fit仍从当前可见初值进行一次求解，不暗中多起点或切换模型。
- 估算振荡频率只是数值初值，不自动输出物理周期结论；y信号与theta信号可以具有不同频率。

### 3. Visible outcomes and useful interpretation

- 点击后直接在当前图旁显示已开始 / 被阻止原因；运行中显示已用时、可取消，完成 / 失败 / 取消不要求用户翻页找信息。不承诺固定延迟或虚构百分比 / ETA。
- 成功时显示当前叠图、参数、具有单位的典型偏差、相比同样本常数均值基线的改善；详细solver数据仍可展开。
- S0明确指标名称 / 公式 / 边界。用户能检查比较使用的同一批实际样本；常数 / 近常数及不可比较情形必须返回清楚的不可评估状态，不制造精度 / 置信度分数。
- 区分求解成功、解释力和物理模型正确；拟合残差不等同真实测量不确定度。常数拟合可以合法成功，但要说明它只估计平均水平，没有解释时间起伏。
- 公式换算失败单独显示，如`Fit completed; period was not calculated`及缺Omega原因；保留用户原表达式并提供编辑 / 移除或转到重复间隔工具的下一步。
- 即使新旧曲线很接近，也应说明本次是否执行、参数 / 偏差是否变化；不靠人为制造曲线差异显示“有效果”。
- 重复间隔直接展示事件数、可用间隔、均值 / 离散及适用含义；0事件是无法估计，不是零周期。

### 4. Attempt records, independent of successful result slots

- 每次发起Fit请求留简要记录：身份、源量 / 区间、源引用或不可用原因、公式、参数初值 / 约束、开始 / 结束、耗时、状态 / 原因、可获得的求解摘要及换算状态。包含前置校验拒绝、失败、取消、成功。
- 自动预览不计作正式拟合尝试，不记录每个按键；禁用入口已有原因时不伪造一个已提交的求解任务。
- 项目内版本化尝试日志与成功结果槽解耦，发生过的尝试不因下次状态刷新而丢失，不要求用户额外保存才能留下失败诊断。未保存工程先缓存在本会话，首次保存项目后纳入该项目；准确写入位置 / 生命周期由S0 ADR冻结。
- 图旁提供最近尝试回看；历史摘要不自动激活为有效结果。复用设置 / 重新计算必须显式，仍经源 / 目标 / 时序守卫。
- 不重复复制整套轨迹，不建立全部历史预测 / 残差版本库；未知日志版本原文保留、只读或提示不支持。中断尝试、截断 / 损坏日志、换工程 / 关闭 / 保存冲突、写入失败的处理在S0固定并测试。
- 不能宣称恢复P6.3时期根本未记录的失败 / 未保存历史。

### Explicit Non-goals

英文版继续开发，翻译 / 国际化后续；本轮不重做Acquire或整个应用入门。无固定毫秒级SLA / 新手完成时限，不自动认定物理模型，不支持任意公式万能猜初值，不增加自动多起点或更换拟合目标。ODE / 联立 / 参数CI、系统误差、完整模型历史对比、批量导出、打包均不纳入。没有新依赖；如实施确需引入，须另行确认。
