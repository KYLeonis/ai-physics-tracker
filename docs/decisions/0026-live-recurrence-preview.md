# ADR-0026 — 重复间隔源自动准备与交叉点草稿预览

## Status

Accepted，2026-10-18；用户同意“改参考线或方向后自动预览交叉点，正式Measure仍显式”。仅扩展ADR-0025中重复间隔仍显式准备源的条款，其余保护不变；实现状态以重构进度表为准。

## Context

公式拟合已按ADR-0025自动准备源，配方事实已收拢到source_recipe。重复间隔页仍要求切Charts手动准备，并且只有正式Measure才得到交叉点，难以看出参考线调整效果。用户要求两个工具连贯。

## Decision

- 当前可编辑重复间隔页复用同一已知源准备路径 / 正式批次执行器；仅所选轨迹对应组，沿用其已确认配方。缺少物理输入、未知 / 损坏 / 重复 / 冲突源不静默覆盖。
- 两个工具复用SignalPreview的合并请求、独立预览executor和旧值拒绝；application预览计算只使用冻结输入，沿用measure_recurrence，不创建或发布正式结果。
- 编辑参考值、方向、区间、源或抑噪设置更新草稿候选交叉点，并明确标注Preview / not measured。Measure才生成 / 发布正式记录；预览不写尝试日志、结果Undo或覆盖历史。源更新仍是既有派生事务。
- 改参考线时只更新候选标记，源数据未变则保留图与交互范围；切方法 / 目标 / 工程 / 工作区或进入历史，旧请求失效。只读历史不触发补齐或预览；保存忙推迟发布，取消 / 失败不无条件重试。
- 科学算法、事件时刻的绝对 / 相对时间、缺测断段、wrapped跳变、确认带与最小间隔不变；候选交叉点不被称为已测周期。

## Consequences

工具页相关编辑会触发有限的后台预览和必要源准备；正式用户意图与结果事务仍明确。没有新增依赖、文件格式、全局队列或状态容器。本轮需独立复审、双平台CI及新的交互HR。
