# ADR-0012 — GUI 跟踪任务边界与轻量校验

## Status

Accepted（2026-08-31；用户确认 4.4 方案，并明确要求取消过度哈希校验）。

## Context

4.3 的同步准备、结果解析和反复 SHA-256 扫描不能直接接到 GUI。保存副本替换活动
session 会破坏任务归属；全帧预测也不能每帧重建全部图元。产品是本地实验工具，
不需要针对“内容被替换但元数据保持相同”的防篡改设计。

## Decision

1. 保留 ADR-0011 的 spawn 引擎隔离。GUI 捕获不可变请求；子进程独占准备、DLC
   训练/评价/推理与自己的 reader，不操作 Qt 或活动 ProjectSession。
2. 结果读取、候选观测合并和日志读取使用后台线程中的独立会话快照。GUI 只确认
   当前会话、媒体代际和输入版本并提交候选；输入变化时重建候选，不覆盖期间编辑。
   使用现有 task runner 与一个轻量 GUI TrackingActions，不建立队列调度系统。
3. AI 链路不再强制或反复计算模型/视频/配置/交换文件 SHA-256。保留路径、存在性、
   大小/修改时间、所选 snapshot、帧号、confidence、时序、first-wins 和原子提交校验。
   旧 hash 字段保留读写，但不作为 AI 使用门禁；媒体显式重连与依赖下载校验不变。
4. 普通保存保持活动 session 身份，以实际保存的快照更新 clean 基线，不吞掉保存期间
   的任务状态/编辑。确认导航后异步取消并回收旧任务，再保存/切换；返回不取消任务。
5. 临时阶段（准备/评价/导入/取消中）仅用于 UI，不改变持久化状态枚举。恢复项目时，
   无活动 worker 的未完成任务在内存标为 interrupted failure，后续正常保存才写回。
6. 日志为 `data/engines/<run_id>.log`；任务结果交换文件放在对应 run 目录。GUI 显示
   有界日志和最新进度；模型评价使用原生指标与单位，评价失败不伪称模型没有产出。
7. Manual 圆形、AI 空心菱形；历史轨迹绘制缓存，当前帧高亮独立更新。图表沿用显式
   Recompute。K-means 留在 Phase 5，届时调用 DLC，不在 4.4 添加选帧实现。

## Consequences

- 不改项目 schema、不新增依赖；不再重复扫描大文件。不能检测保持元数据不变的外部
  内容替换，这是用户确认的取舍。用户应避免在任务运行中外部覆盖视频/模型。
- 原始预测、人工修正、模型与已完成历史仍保留；不自动删除任务产物或重写历史。
- GUI 交互须 Human Review；Windows/CUDA 条件另行落实，当前不假定已通过。
