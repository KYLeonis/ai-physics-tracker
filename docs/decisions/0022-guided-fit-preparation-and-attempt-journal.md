# ADR-0022 — 可检查的拟合准备、解释与尝试日志

## Status

Accepted for implementation，2026-10-16；P6.3.1用户已确认范围并授权实施，Issue #31。实现正确性仍须独立复审和本轮HR。

## Context

用户需要看到当前公式实际在做什么。ADR-0021的成功结果槽继续负责科学结果；每次试用的诊断不能挤进该槽或Undo事务。自动准备不得替用户认定物理模型、覆盖手改或绕过时序授权。

## Decision

- 结构识别只接安全AST：单参数常数、`a*t+b`、`a*t^2+b*t+c`、`c+A*cos(w*t+p)`、`c+A*exp(-b*t)*cos(w*t+p)`，允许加法/乘法换序、括号及参数改名。角色必须独立且全部覆盖；其余结构人工输入。首选示例可填估算；手改参数/边界/Fixed或恢复设置后，自动覆盖关闭；换数据只提示重新估算。显式采用也保留边界/Fixed，若任何自由参数建议越界则整批拒绝。
- 线性/二次用缩放时间最小二乘；振荡只用至少两个可辨认周期、单个连续近均匀段、至少24个样本的去趋势频谱初值及线性正余弦投影，阻尼用分窗振幅趋势作初值。频率初值不等于物理周期。缺测、多段、wrapped跳变、信息不足时可拒绝估算；仍可手填拟合。正式拟合仍是一次既有求解。
- 预览为当前草稿，不发布DerivedData。编辑合并后在主线程准备不可变快照，数值计算在既有单executor执行；generation/配方/上下文变化后拒绝晚到值。正式任务优先，自动预览不生成拟合尝试。预览错误清除旧草稿曲线；旧成功值通过显式Previous saved result回看。
- 典型偏差定义为`RMSE = sqrt(mean((prediction-measurement)^2))`，单位沿用源。基线是同一批实际样本的常数均值，`baseline_RMSE = sqrt(mean((measurement-mean)^2))`；改善为`100*(1-RMSE/baseline_RMSE)%`，可为负，不截断。基线小于等于`64*eps*max(abs(measurement))`或零时不可评估。非有限或溢出不输出伪数值。残差不是测量不确定度，收敛不是物理正确。
- 尝试日志独立存于项目`analysis/fit-attempts.json`，顶层`version=1, project_id, attempts`。每次请求先记running，再记终态；同步拒绝记rejected；包括初值/约束/换算表达式、源ID及指纹、时间/区间、结果摘要/耗时/失败原因，不含整套样本或预测。使用临时文件+原子替换；日志不修改Project、dirty或Undo。
- 未保存项目在会话缓存；首次保存/Save as成功后在新根目录写入当前日志，原工程日志保留。普通保存不写日志，无跨线程共享写；GUI主线程在save busy结束后同步根目录。关闭/换工程先将运行项记interrupted并落到原根目录；迟到任务不写新工程。重开发现running呈现interrupted。不能恢复实施前未记录的尝试。
- 未知版本、project_id不符、损坏/截断日志保留原字节且只读，显示原因；不自动覆盖。兼容同版本未知字段原样保留。IO失败保留内存记录并明确提示未落盘，可主动重试；不得宣称已保存。读取历史不激活结果，不越过当前prepare守卫。

## Frozen verification fixtures (before implementation)

- t=0..8，241点：`3*t-2`；`0.7*t^2-2*t+5`；改名/换序同义式。无噪声估算后的单次拟合参数误差<=1e-7、预测RMSE<1e-8；相对时间原点转换到0..8不改变所代表曲线。
- t=0..12，601点：`0.4+2*exp(-0.08*t)*cos(2*pi*0.8*t+0.3)`及无阻尼版。估算频率相对误差<=10%，估算后既有单次拟合预测RMSE<1e-8、参数误差<=1e-6。另用seed=631、噪声std=0.03，频率误差<=5%，拟合RMSE<0.04；不把噪声残差当真值不确定度。
- 振荡相位-1.2、幅度缩放1e-6/1e6；同等频率和相对误差要求。不足2周期、常数/近常数、<24点、多连续段、wrapped跳变、未知`sin(t*t)`应明确不可估而非编造。原P6.3容差/P011协议不变。
- 解释：线性精确拟合改善100%；常数平均拟合改善约0%；比均值更差可负；恒定/近常数基线不可评估；同样本长度/有限校验。
- 日志：所有终态、同步拒绝、重开running、中断/换工程、未保存首存/另存、损坏/未来版本/扩展/写失败、Undo独立。图形：快速编辑只呈现最新草稿，保护人工参数与恢复值，正式失败保留旧成功值可回看。

## Consequences

不引入依赖或迁移Project schema。独立日志不是完整历史结果库，其丢失不影响科学结果；损坏时需用户先另存/移走原日志才能恢复写入。自动估算宁可拒绝，也不暗中换模型或猜物理参考。
