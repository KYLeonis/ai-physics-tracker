# ADR-0025 — 公式拟合的源曲线自动准备

## Status

Accepted，2026-10-17。用户grill-me确认先改善公式拟合体验，并明确回复“自动补齐”。

## Context

P6.3.1已经有自动草稿预览，但缺少或过期的源仍要求切页手动Recompute。用户要求相关修改后联动更新，并先改善体验、再做内部整理。ADR-0009的普通图表显式重算保持；这里只改变当前公式拟合页的依赖准备触发方式。

## Decision

- 当前可编辑公式拟合页，在需要的已知线性 / 角量源缺失、过期或与当前已确认计算设置不符时，自动准备所选轨迹的对应分析组。复用现有kinematics / angular job、单个正式执行器、输入 / 目标版本校验及Session原子提交；既有每组四种量不拆成新的存储契约。
- 只沿用当前SG参数和显式确认的角参考；角量仍需标定，不猜支点 / 方向。缺少前提就地显示原因；不把未知步骤、重复源或不支持的记录当作可自动覆盖的缺失数据。
- 补齐成功刷新当前草稿预览、单位和说明；不会自动Fit、不会记正式拟合尝试。上游源替换按既有规则将历史拟合标stale并保留；补齐是既有派生事务，raw与时间不变。
- 切轨迹 / 区间 / 参数 / 工程 / 工作区、查看只读历史或取消后核对上下文，迟到结果丢弃。取消 / 失败不自动循环重试；用户重新编辑或显式预览可重试。保存忙时延迟发布，仍保持结果版本核对。
- 自动预览继续独立执行（ADR-0023）；只读历史 / 保存 / 无关结果变化不启动补齐。普通Charts与重复间隔流程本轮保持显式重算。

## Consequences

进入拟合或相关输入变化可能生成新的上游派生结果并产生既有Undo步；界面须说明正在更新源。自动触发不意味着自动改变物理定义或科学结论。没有新增依赖、schema迁移、全局调度器或通用依赖图；本轮需独立review、双平台CI与新的真人HR。
