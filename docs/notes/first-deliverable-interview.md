## 决策树与当前前沿

- 根A：主要用户与要完成的任务 → 实验 / 视频边界 → 首发必要功能与输出 → 验收与试用。
- 根B：原创代码的授权意愿 → 具体许可与历史决策衔接 → 第三方 / 模型边界。
- A / B明确后：分发对象、平台与安装要求 → 运行环境 / 权重交付 → 版本范围及完成条件。
- 所有分支闭合后：汇总共同理解，等待用户确认，再冻结计划与正式许可 / 分发决定。

当前前沿为Q8复核范围、Q9真实样例与授权、Q10Mac首次打开门槛；后续还需收敛具体素材、安装 / 模型交付、教程与试用验收等分支。

## 第一轮

### Q1：主要用户与目标任务（已确认）

建议：先面向大学物理实验的学生 / 教师，让他们把一段二维实验视频处理成可复核、能用于实验报告的数据和图。

替代方向：优先服务本人 / 科研同行的研究复现，或优先交付通用视频跟踪工具。

用户选择“是，采用这个用户与任务目标”：大学物理实验的学生 / 教师，将二维实验视频处理成可复核、能用于实验报告的数据和图。

### Q2：原创代码的授权边界（新版已确认）

原Q2将开源与继续提供源码绑定，事实补查后已明确替换，不再作为本轮推荐。

当前建议：沿用既有MIT方向，允许使用 / 修改 / 商业使用 / 再分发，保留版权和许可声明；不强制别人的修改版继续开源。第三方库和模型权重各自遵守原许可，商业模型分发条件另行核对。

替代方向：希望改版再分发也必须开源，或希望限制为非商业 / 教育科研用途。用户可自由说明其他目标。

用户对被替换的原Q2回答“希望仅允许教育科研或非商业用途”，随后对明确替换后的新版Q2选择“是，沿用MIT，不强制修改版开源”。按新版明确回答记录原创代码采用MIT的意愿；原答不覆盖新版，也不自动决定模型权重的使用范围。权重边界通过Q5另行确认。

## 第二轮（Q3–Q5已确认）

### Q3：首发任务边界

建议：先保证单视频 / 单目标二维运动的完整流程，含少量人工标注、AI跟踪、困难帧修正、标定 / 分析、导出及保存重开；用单摆和一种直线运动作为首发验收样例。已有多轨迹等功能保留；6.5原单摆验收标准不变。

替代方向：先只保证单摆，或首发即保证多目标 / 两点刚体分析的完整流程。样例、指标和正式验收细节待本题范围确认后继续讨论，不因提出建议修改当前AC。

用户认可推荐：首发保证单视频 / 单目标二维运动的完整流程，验收样例覆盖单摆和一种直线运动；已有功能保留，6.5原验收标准保持。具体直线运动样例与证据仍待后续收敛。

### Q4：首次交付的口径

建议：基于已有Mac arm64发行先例制作当前main的安装版，先给少量学生 / 教师做教学试用，再推进广泛公开发行与Windows正式交付。我们提供安装包、环境安装入口和样例，试用者无需配置Python。

替代方向：当前main首发即公开Mac测试版，或等Windows安装版完成后才认定首次可交付。历史测试发行授权不延伸为本轮新发行授权；现阶段只决定目标。

用户选择“先做Mac小范围教学试用版”。按当前main提供安装包、环境安装入口和样例，无需试用者配置Python；源码沿用MIT公开方向，不给源码增加受邀限制。实际打包 / 分发执行仍待整体共同理解确认及对应Gate。

### Q5：默认AI的商业适用性

建议：原创代码MIT；首发仅验证默认AI路径的教学科研用途，不承诺其所有预训练权重均具商业使用条件。具体模型按原许可核对，商业AI场景再选择并核实相应权重；不把软件MIT改成非商业许可。

替代方向：首发默认AI路径也必须明确支持商业使用。按需下载 / 是否随包附带模型、离线要求与许可材料，在交付口径及本题确认后继续讨论。

用户认可“软件MIT，默认AI的商业适用性分别核实”。首发验证默认教学科研链路，不把软件MIT改为非商业许可，也不据此认定所有模型均能或不能商用。

## 第三轮（Q6 / Q7已确认）

### Q6：报告交付物

建议：CSV数据表、带轴名 / 单位 / 图例的PNG图、简短方法 / 参数说明为首发必需。说明记录视频 / 区间、标定、处理设置与拟合公式等，支撑学生解释结果来源。先核对已有PNG快照是否满足目标；原生Excel、自动PDF报告和跟踪视频后续再排。

替代方向：首发必须同时提供原生Excel或自动PDF报告。具体导出内容 / 结果选择与复核边界在本题确认后继续讨论。

用户认可CSV＋PNG＋方法 / 参数说明作为首发必需；原生Excel、自动PDF报告和跟踪视频导出后续再排。已有PNG快照先核对是否满足轴名 / 单位 / 图例和可读性目标。

### Q7：联网与离线边界

建议：首次准备可联网下载独立AI环境和本次实验所需权重；准备完成后，支持的标注、训练、推理、分析与导出应可离线完成。换未准备模型可再次联网准备，试用者无需配置Python，目标任务在本机处理视频。

替代方向：首次安装也必须完全离线。独立环境与模型交付、容量 / 安装体验及许可材料据此进一步收敛，不先假定两种方案均须实现。

用户认可首次准备联网、准备后离线使用；已就绪的支持流程应可离线完成，新增未准备模型可再次联网准备。试用者无需配置Python，视频在本机处理。

## 第四轮（Q8–Q10待回答）

### Q8：首发复核范围

建议：同机保存重开工程，能核对观测、标定、设置和结果；老师可通过CSV＋PNG＋方法说明检查 / 复算。完整跨机器工程归档后续再排。教学样例单独准备为可在试用机打开的样例，不把现有Save As误作自包含归档。

替代方向：首发必须支持跨机器完整工程复核，需要补齐外部视频等资源的项目打包范围。具体导出内容和复核能力按本题决定，不隐式增加全部Phase 8归档工作。

### Q9：真实教学样例及授权

建议：单摆与直线运动两类均采用真实实验录像，且有供试用者使用 / 分发的授权；后续确定具体素材来源。现有研究授权不自动延伸为试用包分发授权；合成数据用于算法测试。

替代方向：真实单摆＋明确标为合成的直线运动演示。若选择此方向，应保留合成身份，不能将其当作真实直线运动验证证据。

### Q10：Mac首次打开门槛

建议：本次小范围教学试用接受未公证测试包，按Apple的单应用手动放行流程打开；暂不把正式Developer ID签名 / 公证作为本次交付门槛。对新安装包实际验证步骤，不要求关闭全局安全保护，不复用旧发行的一次性授权作为本轮依据。

替代方向：本轮必须完成正式签名 / 公证。是否购买 / 使用开发者计划、实际签名或发布均未执行；本题只确定目标与门槛。
