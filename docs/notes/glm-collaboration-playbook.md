# 项目内 GLM 派工与验收记录

用途：下次派工前读本页，并把相关约束放进任务。只记录有证据的问题、修正方法和验证；不记录账号信息、原始模型日志或对模型能力的笼统判断。运行原始证据保留本地忽略的`.zcode-control/`。

## 派工前

1. 独立worktree、明确拥有的文件和禁止修改范围；给定接口、数据语义、完成判据及真实Python测试命令。
2. 小型实现用Flash；科学/持久化/并发契约先由Codex冻结，复杂审查用GLM-5.3。禁止worker自行再派工、提交、push或修改验收标准。
3. 返回值须列变更文件、测试和未解决项；主Agent检查实际模型、全部diff和新文件。CLI退出0或检查通过都不能替代代码验收。
