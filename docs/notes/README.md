# docs/notes — 交互与体验记录

本目录存放**非规范类**的产品观察记录：真实使用体验、交互摩擦清单、改进方向草案。
与 `docs/spec/`（正式需求）和 `docs/reviews/`（代码审查记录）区分：

| 目录 | 内容 | 何时更新 |
| --- | --- | --- |
| `docs/spec/` | 正式需求、数据语义、验收标准 | 需求变更时（需用户批准） |
| `docs/reviews/` | 每个 Subphase 的代码审查记录 | Subphase 审查时 |
| `docs/notes/`（本目录） | 真实使用体验、交互摩擦、改进草案 | 用户报告体验问题时随时 |

约定：

- 文件命名 `kebab-topic.md`（如 `interaction-experience.md`）。
- 记录**事实与用户原话**优先于解决方案；改进方案标注为"草案"，实施前走正常 Subphase 流程。
- 结论性的产品变更仍需进入 spec / plan，并在其中引用本目录的记录。
