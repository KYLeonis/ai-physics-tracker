## 1. 目标与边界

从已有有效观测得到可追溯的角运动、相图、周期、拟合和误差说明。
基准仍为平面单摆；同时支持同视频两点定义的刚体平面方向和多轨迹分析比较。
复用现有 NumPy/SciPy、DerivedData、后台快照计算与 PyQtGraph，不新增依赖。

FFT、一般参数识别、能量分析、完整非线性动力学求解保持 roadmap 的后续研究状态。
模型库、批量导出、安装打包和多相机/3D 不属于本阶段。

## 2. 不变式

- raw 层仍仅存像素，世界坐标由当前标定派生；时间由 Timeline 按源帧计算。
- 计算需当前时序授权；缓存可只读查看，stale 结果不得参与结论性分析。
- 缺测不插值；unwrap、平滑、求导、周期配对都不得跨越缺测段。
- SG 沿用 ADR-0008 的窗口、阶数、短段规则，显式 `delta=1/fps_nominal`。
- 参数、观测、参考点、标定或时序改变后，相关结果失效；异步结果提交前复核全部输入。
- 原子提交/Undo、未知字段保留、保存重开遵守 ADR-0009，不更改 AI 激活语义。
- 科学量、单位、有效区间、方法假设及失败原因必须可见；不把拟合成功等同于模型成立。

## 3. 功能需求

### R1 — 角运动

明确区分两种定义，不把任意位置相对坐标原点的极角默认为摆角：

- **单摆**：用户指定固定支点和摆球轨迹。在 y 向上的世界坐标中，
  `theta = atan2(world_x - pivot_x, -(world_y - pivot_y))`，向下为零，向右摆动为正。
  世界负 y 轴作为重力参考方向，用户必须先把坐标轴与实验竖直方向对齐。
- **刚体方向**：同视频有序两轨迹 A→B，
  `theta = atan2(world_y_B - world_y_A, world_x_B - world_x_A)`，+x 为零，逆时针为正。
  只使用两条轨迹同帧都有有效点的交集；两点重合时该帧无定义。

固定支点保存为像素参数，并使用与摆球相同的标定变换。R1 首版要求有效标定，
不增加未经标定的角度模式。完整输出包括原始角度、段内 unwrap 后的平滑角度、
角速度和角加速度；单位分别为 rad、rad/s、rad/s²，显示可转 degree，但计算不转。
各连续段独立 unwrap；缺测前后的整周偏移无法从观测确定，不声称恢复跨段转数。
短段不足以求导时保留可定义的原始角度，不造速度/加速度。

### R2 — 图表与交互

在既有“分析与图表”工作区增加 θ(t)、ω(t)、α(t)、θ–ω 相图及现有量的相空间视图
（如 x–vx）；允许选择多条轨迹进行同量比较。
时间图使用绝对源帧时间；相图携带源帧号，点击定位视频；缺测断线、stale 提示和
异步输入变化拒绝沿用现有行为。角度配置、曲线单位和计算参数可检查。

### R3 — 周期与拟合

> 下列为旧草案，不作6.3已接受范围。用户已确认显式函数编辑 / 单标量拟合与独立周期工具；6.3已冻结计划明确区分信号同向交叉重复间隔与物理周期，不能用单摆示例约束所有模型。用户已最终认可，验收以[6.3子计划](../status/phase-6.3-plan.md)为准。

- 周期分析先支持角信号同方向零交叉的段内配对，线性估计相邻样本间的交叉时间；
  这不补写观测，也不跨缺测插值。输出每次周期、区间、数量、均值和样本标准差。
  零水平需明确（摆角零点或用户设定偏置），噪声重复交叉需去重，参数留痕。
- 数据拟合先提供线性、二次多项式，以及单摆小角度阻尼正弦
  `theta(t) = c + A*exp(-beta*(t-t0))*cos(Omega*(t-t0)+phi)`。
  `t0` 是记录的拟合区间起点；该模型只描述欠阻尼小角度近似，
  `2*pi/Omega` 是阻尼振荡周期，不直接当作无阻尼固有周期或用于推断 g。
- 明确拟合的源量、输入区间、参数初值/约束、实际样本与权重。
  使用有限且有效的观测样本；不重新编号时间、不拟合 stale 数据。
  多段样本可共享模型拟合，但缺口及各段来源必须保留并披露。
- 输出参数、预测、残差、RMSE、有效样本数、收敛状态；不足数据、常量信号、
  不可辨识参数或求解失败给出原因，不发布貌似正常的有效结果。

### R4 — 比较与误差解释

2026-10-24用户在P6.4 grilling Q2明确取消新增两轨迹比较 / 同帧差值；原差值草案不再作为Phase 6实施或验收要求。R2 / AC-3的既有多轨迹叠图保留，不删除已交付能力。当前P6.4只推进参数误差解释，具体支持边界见[mini-plan](../status/phase-6.4-plan.md)。
展示周期的样本离散程度、拟合残差、端点/窗口影响与时序近似来源。
参数标准误差若由局部协方差估计，必须披露独立同分布残差及局部线性近似条件；
不可估计时输出“不可估计”，不能用零代替。AI confidence 不换算成坐标或参数误差。
首版不声称完整系统误差传播；比例尺、支点和时间的系统偏差需作为局限明确列出。

### R5 — 数据与生命周期

优先使用既有可变列宽 `DerivedData.values` 与 additive 扩展；不强行让角度变成两列 x/y。
双轨迹输入依赖、标量 kind 注册、参考参数、拟合摘要落点及失效传播由 6.1/6.3 ADR 定义。
特别检查参考轨迹编辑/删除、首次标定、标定切换、Undo/Redo、保存重开与后台迟到结果。
不能仅靠主 `track_id` 标记失效，也不能把现有四项 `KINEMATICS_KINDS` 当成通用结果集。
如 additive 方案不足，先提出兼容性/迁移方案，按 AGENTS.md 决策门处理再实现。

## 4. 验收与证据

| 编号 | 可验证结果 | 证据与建议门槛（待确认） |
| --- | --- | --- |
| AC-1 | 单摆与两点方向的 θ/ω/α 定义正确 | 基准方向、符号、跨 ±π、恒定角速/角加速、缺测与重合点测试；解析原始角度绝对误差 ≤1e-10 rad |
| AC-2 | 平滑/导数的单位与精度正确 | 无噪声 θ=0.2 sin(πt)，60 fps、20 s、SG 7/2；去掉每段两端半窗口后，ω/α 的 RMSE 除以解析峰值分别 ≤2%/5%；端点另行报告 |
| AC-3 | 角运动图、相图与多轨迹比较可用 | offscreen 测试 + 用户 Human Review；帧定位、单位、缺测断线和 stale 行为 |
| AC-4 | 周期与阻尼拟合可复现 | 同 AC-2 采样，≥5 个完整周期；无噪声周期相对误差 ≤1%；阻尼信号 A=0.2 rad、beta=0.1/s、Omega=π rad/s、c=0.03 rad、phi=0.3 rad 的 Omega/beta 相对误差 ≤1%/10%；失败输入不输出有效拟合 |
| AC-5 | 真实单摆的周期符合 roadmap 验收 | 实现前冻结视频、区间、≥5 个周期的独立人工帧时序参考及参数；自动周期与参考均值相对差建议 ≤5%；说明同视频时序参考不等于独立校时 |
| AC-6 | 误差说明与溯源可解释 | 区分残差、样本离散、参数条件性标准误差、系统误差；拟合不可辨识、时序近似及缺测有明确提示 |
| AC-7 | 保存/重开/Undo 与后台提交一致 | 新分析 round-trip、参考依赖失效、取消/迟到拒绝、未知字段保留；旧项目与四种运动学结果不退化 |

保留失败证据并请求调整，不重写已接受验收。阶段收尾仍逐项核对 roadmap 的两项标准。
