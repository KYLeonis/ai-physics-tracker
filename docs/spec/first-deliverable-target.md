## Goal

让大学物理实验的学生 / 教师，在Mac arm64上把**单视频 / 单目标二维运动**处理成可复核、能用于实验报告的数据和图，完成首次小范围教学试用。

完整流程为：人工标注→训练→AI跟踪→困难帧修正及必要的再训练→标定 / 物理分析→导出→同机保存重开。首次学习沿用当前20个人工帧门槛，已有多轨迹等功能保留。

## Scope与完成证据

以下是本版必须满足的交付目标，勾选只表示已有相应完成证据。

- [ ] **FD-1 完整任务**：在真实单摆上完成上述工作流及同机保存重开，能复核观测、标定、设置与结果；原6.5 AC逐条保留并验收。
- [ ] **FD-2 报告材料**：导出CSV数据、带轴名 / 单位 / 图例且可读的PNG，以及简短方法 / 参数 / 来源说明。说明包括视频 / 区间、标定、处理设置与拟合公式等，老师可据此检查和复算。
- [ ] **FD-3 真实教学样例**：提供一份有供试用者使用 / 分发授权的真实单摆视频及教学材料，固定实际文件、参数与参考。P011的6.5冻结协议不因教学素材选择回改。
- [ ] **FD-4 四类合成样例**：匀速直线、匀加速直线、二维抛体、简谐振动，每类一套可复现参数，明确标为合成。逐帧保留像素 / 物理坐标、解析运动学真值及参考图；一维给s–t / v–t / a–t，二维按x / y分量展示，记录坐标、时间与单位。
- [ ] **FD-5 独立对照资料**：四类均提供真值数据、参考图及训练 / 跟踪后对照报告。分别核查纯AI预测、人工修正后最终轨迹，区分已标注 / 未标注帧误差并单列缺测；真值不自动灌入训练标签。对齐帧 / 时间 / 单位，区分跟踪与数值处理影响。新基准与Phase 5 AC-9分开记账，不增加首轮独立用户必做样例数。
- [ ] **FD-6 可安装及离线运行**：提供当前main的Mac arm64安装包、独立AI环境准备入口、样例与教程，无需试用者配置Python。首次可联网下载环境 / 所需权重，准备后支持的标注 / 训练 / 推理 / 分析 / 导出可离线完成；换用未准备模型可再次联网准备。接受未公证包的单应用手动放行，对本次新包实际验证步骤，不要求关闭全局保护。
- [ ] **FD-7 许可材料**：原创代码采用MIT，依赖 / 二进制 / 权重按具体发行内容核实并提供相应材料。首发验证默认AI教学科研路径，不承诺全部权重可商用；安装包不附第三方预训练 / 教师权重，首次准备从核实来源下载并保留来源 / 许可记录，训练后模型保存在学生本机。当前仅代码MIT文本及元数据已落实，具体发行材料尚待准备。
- [ ] **FD-8 独立用户完成任务**：至少一名未参与开发的目标用户按教程独立完成真实单摆的完整任务。用户协调试用者，我们准备安装包、样例、教程和问题记录；不设完成时限，额外指导 / 代操作如实记录。阻断任务、丢失数据或科学输出错误修复后再宣布本版完成；原自动测试及用户Human Review继续执行。

真实单摆与合成核查分别提供证据。四类合成结果不代表真实录像的通用精度，固定检查集汇总RMSE也不等于全轨迹精度。参数、帧率、误差指标、训练暴露记录与数值门槛在相应基准运行前凭证据固定，不事后按结果倒推。
